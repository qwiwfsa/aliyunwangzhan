快速开始

1. 访问 登录页面 使用 admin / admin123 登录

2. 进入页面管理，点击"新建页面"创建新页面

3. 点击"编辑"进入可视化编辑器

4. 在左侧编辑内容，右侧实时预览

5. 点击预览区域的元素进行元素级编辑

6. 使用"图片库"上传和管理图片
