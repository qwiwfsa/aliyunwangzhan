## 🚀 部署步骤（共4步）

### 步骤1：宝塔面板创建网站

1. **登录宝塔面板**
   - 打开浏览器访问：`http://47.95.236.85:8888`（宝塔默认端口）
   - 输入宝塔账号密码登录

2. **创建网站**
   - 点击左侧菜单「网站」
   - 点击「添加站点」按钮
   - 填写信息：
     - 域名：`api.yaozijin.com`（或先用 `47.95.236.85`）
     - 根目录：`/www/wwwroot/api.yaozijin.com`（默认）
     - PHP版本：选择 `7.4` 或更高版本
     - 数据库：不创建（已创建好）
   - 点击「提交」

3. **确认创建成功**
   - 网站列表中会出现 `api.yaozijin.com`

---

### 步骤2：上传网站文件

1. **进入文件管理**
   - 点击左侧菜单「文件」
   - 找到并进入 `/www/wwwroot/api.yaozijin.com`

2. **上传文件**
   - 点击「上传」按钮
   - 选择以下文件/文件夹上传：
     - `admin/` (整个文件夹)
     - `cms/` (整个文件夹)
     - `server.js`
   - 等待上传完成

3. **上传方式说明**
   - 小文件：直接拖拽上传
   - 大文件/文件夹：先压缩成zip，上传后解压
   - 上传完成后，确保文件结构如下：
     ```
     /www/wwwroot/api.yaozijin.com/
     ├── admin/
     ├── cms/
     └── server.js
     ```

---

### 步骤3：初始化数据库

1. **进入数据库管理**
   - 点击左侧菜单「数据库」
   - 找到 `yaozijin` 数据库
   - 点击「管理」或「phpMyAdmin」

2. **导入SQL文件**
   - 在phpMyAdmin中，点击「导入」标签
   - 点击「选择文件」
   - 选择 `数据库初始化.sql` 文件
   - 点击「执行」按钮

3. **确认导入成功**
   - 应该看到4个表被创建：
     - `cms_pages` - 页面表
     - `cms_sections` - 区块表
     - `cms_categories` - 分类表
     - `cms_articles` - 文章表

---

### 步骤4：启动Node.js服务

#### 方式A：使用PM2管理器（推荐）

1. **安装PM2管理器**
   - 点击左侧「软件商店」
   - 搜索「PM2」
   - 找到「PM2管理器」并安装

2. **添加Node.js项目**
   - 打开「PM2管理器」
   - 点击「添加项目」
   - 填写信息：
     - 项目目录：`/www/wwwroot/api.yaozijin.com`
     - 启动文件：`server.js`
     - 项目名称：`cms-upload-server`
   - 点击「提交」

3. **确认启动成功**
   - 在PM2管理器中看到状态为「运行中」

#### 方式B：使用终端启动

1. **打开终端**
   - 点击宝塔面板右上角「终端」图标
   - 或左侧菜单「终端」

2. **执行命令**
   ```bash
   cd /www/wwwroot/api.yaozijin.com
   npm install express multer cors
   nohup node server.js > server.log 2>&1 &
   ```

## 🔧 常见问题

### 问题1：访问后台显示403错误
**解决：**
- 检查文件权限
- 宝塔面板「文件」→ 选中文件夹 → 点击「权限」→ 设置为755

### 问题2：数据库连接失败
**解决：**
- 确认 `admin/api/config.php` 中的数据库配置正确
- 检查MySQL是否运行：宝塔「数据库」→ 看状态

### 问题3：图片上传失败
**解决：**
- 检查 `cms/uploads` 目录权限为777
- 宝塔「文件」→ 选中 `uploads` → 「权限」→ 777

### 问题4：Node.js服务无法启动
**解决：**
- 检查端口3000是否被占用
- 在PM2管理器中查看错误日志

## 🔒 安全建议

部署完成后，请立即修改：

1. **修改后台登录密码**
   - 登录后台 → 修改密码

2. **修改数据库密码**（可选）
   - 宝塔「数据库」→ 修改密码
   - 同步修改 `admin/api/config.php`

3. **配置防火墙**
   - 宝塔「安全」→ 放行端口：80, 443, 3000

4. **域名备案后配置SSL**
   - 宝塔「网站」→ 选择站点 → 「SSL」→ 申请Let's Encrypt证书
